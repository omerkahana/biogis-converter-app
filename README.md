# BioGIS Converter

אפליקציית Streamlit להתאמת שמות מינים, העשרת תצפיות BioGIS והפקת דוחות להורדה.

## הרצה מקומית

```bash
pip install -r requirements.txt
streamlit run app.py
```

## הרשאות Google Sheets

האפליקציה קוראת את הגיליון לפי SHEET_ID בתוך app.py.
כדי שקריאה תעבוד, צריך:

1. ליצור Service Account ב-Google Cloud.
2. להוריד JSON key.
3. להעתיק את פרטי ה-JSON אל `.streamlit/secrets.toml` לפי הדוגמה בקובץ `.streamlit/secrets.example.toml`.
4. לשתף את Google Sheet עם כתובת ה-client_email של ה-Service Account בהרשאת Editor.

## אינדקסים ופלטים

האפליקציה קוראת את `plants_index`, `animals_index`, `butterflies_index` ואת `name_mapping` מאותו Google Sheet. יש ליצור את גיליון הפרפרים לפני הפעלת הגרסה הזאת. שמות הגיליונות וכותרות העמודות חייבים להתאים לקבועים ב-`app.py`.

פרפרים מזוהים לפי שם רשמי, שם קודם מהאינדקס, תיקון מאושר או קבוצת BioGIS מפורשת. גיליון הפרפרים כולל את `שם המין`, `שם מדעי`, `משפחה`, `שם עברי קודם` ואת העמודה `שמות חלופיים להתאמה` (מופרדת בנקודה-פסיק). ניקוד מוסר לצורך ההתאמה בלבד. מינים שלא נמצאה להם התאמה עוברים למסך התיקונים; אפשר לשמור תיקון או להוסיף מין חדש לאינדקס הפרפרים.

קובץ הפרפרים שסופק כולל הערכת שימור **ים-תיכונית בלבד**. היא נשמרת בעמודת `סטטוס שימור ים-תיכוני`. סטטוס אזורי/ישראלי וסטטוס עולמי נשארים ריקים כאשר אינם מסופקים, ואינם נגזרים מהסטטוס הים-תיכוני. פרטים מתתי-מינים ואוכלוסיות נשמרים כשמות נפרדים.

הורדת Excel כוללת גיליון `butterflies_report`, ויש גם כפתור נפרד להורדת `butterflies_report.csv`. הפרפרים אינם משוכפלים בדוח חסרי החוליות האחרים. קובץ התצפיות ל-GIS כולל שדה `mediterranean_conservation_status` נפרד; השדה `classification` משתמש רק בהערכה האזורית/העולמית כשישנה.

## בדיקות

```bash
python -m unittest discover -s tests -v
```

הבדיקות מבודדות את ממשק Streamlit ואת לקוח Google, ובודקות את העיבוד, התאמת שמות קודמים, תאימות לקבוצות הקיימות, תיקונים וייצוא CSV/Excel. אין צורך בחיבור ל-Google להרצתן.

## עריכה ושמירה בטבלת התיקונים

שינויים בתוך הטבלה נשלחים יחד רק בלחיצה על `Save checked ... corrections`, כדי שבחירת `Action`, סימון `Save` או עריכת שם לא יפעילו מחדש את עיבוד התצפיות. יש לסמן `Save` בשורות הרצויות ולשמור לפני שינוי סף הסימון האוטומטי או העלאת קובץ אחר. קריאת CSV, העשרת תצפיות ויצירת קובצי ההורדה נשמרות במטמון מוגבל. התאמת שמות מתבצעת פעם אחת לכל צירוף של שם מנורמל וקבוצה, גם כשיש תצפיות רבות לאותו מין. לאחר שמירה מתרעננים רק האינדקס הרלוונטי וטבלת תיקוני השמות.

להוספת צמח שאינו באינדקס, בוחרים `Add as new species to index`, ממלאים `New Hebrew name` ואת מאפייני המין ומסמנים `Save`. במצב זה השדה `Correction from index` אינו בשימוש. גלילה ימינה מציגה גם אנדמיות, זר/פולש, מוגן, סיכון, מין אדום, צורת חיים, הסרת נוף עונתית, בית גידול, תפוצות, קוד, קישור ומספר צמח. כל שדה נשמר בעמודה המקבילה באינדקס.

למין פולש מזינים `פולש` ב־`Classification`, ומשתמשים ב־`Alien / invasive status` לפירוט שנשמר בעמודת `זר`. השדה `Classification` נשמר ב־`סיווג` ומשמש גם בייצוא ל־GIS. פרטי בית הגידול, צורת החיים והתפוצות נכללים בדוח הצמחים לפי האינדקס.
